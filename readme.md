# 闪烁风险判定知识整理（GB 40070-2021 / IEEE 1789-2015）

LightSense 频闪仪 (Flicker Meter) 的合规判定功能当前基于**中国强制性国标
GB 40070-2021《儿童青少年学习用品近视防控卫生要求》**（教育照明频闪限值）。
本文同时整理其依据与蓝本 **IEEE Std 1789-2015** 的核心知识，以及本项目中的实现方式。

## 1. 背景与目的

LED 光源对电流变化响应极快（无白炽灯的热惯性），驱动电流的纹波会直接复现为光输出波动
（闪烁，Temporal Light Artifact, TLA），可能导致：

- 头痛、偏头痛、视疲劳
- 癫痫发作（低频强刺激，约 3~70 Hz 敏感）
- 频闪效应（stroboscopic effect）导致运动物体运动感失真，工业环境有安全隐患

国内将此纳入近视防控体系：GB 40070-2021 由国家卫健委提出归口，2022-03-01 起强制实施，
全部技术内容为强制性，教室照明灯具不满足要求不得上市。

## 2. 基础度量

| 度量 | 定义 | 特点 |
|---|---|---|
| 波动深度 / Percent Flicker (m) | `m = 100% × (A − B) / (A + B)`，A/B 为波形最大/最小光输出 | 只看峰谷幅度，与频率、波形形状无关；**国标"波动深度"与本指标公式完全相同** |
| Flicker Index (FI) | 平均光输出线以上面积 / 总面积（一个周期内） | 考虑波形形状，方波 100% 调制 → 0.5，正弦 100% → 约 0.32；国标不考核，本项目作为补充输出 |
| Pst^LM | IEC TR 61547-1 短时闪烁严重度，`Pst = sqrt(Σ(m_k·H(f_k))²)` | 国标教育照明采购普遍要求 Pst^LM ≤ 1；本项目已实现谱估计版 |

## 3. GB 40070-2021 频闪限值（本仪表判定依据）

国标表 4 对教室/台灯灯具的光输出波形**波动深度限值**：

| 光输出波形频率 f | 波动深度限值 |
|---|---|
| f ≤ 10 Hz | 0.1 % |
| 10 Hz < f ≤ 90 Hz | f × 0.01 |
| 90 Hz < f ≤ 3125 Hz | f × 0.032（= 0.08/2.5） |
| f > 3125 Hz | 免除考核（高频豁免） |

典型值：60 Hz → 0.6%；100 Hz → 3.2%；120 Hz → 3.84%；1 kHz → 32%。

配套要求（教育部各地教室照明改造技术指引普遍引用）：
光闪烁按 IEC TR 61547-1 测得的 **Pst^LM ≤ 1**，且不得超过制造商声称值。

国家卫健委标准解读明确：波动深度要求"与 IEEE Std 1789-2015 保持一致"，
即国标以 IEEE 1789 的 NOEL（无可观察效应）线为主干并做了工程化修改
（f≤10Hz 定为固定 0.1%；90Hz 以上斜率放缓为 0.032 并延伸至 3125Hz 豁免）。

### 判定规则（固件实现）

```
f > 3125 Hz            → EXEMPT (免除考核)
m ≤ 对应频段限值        → PASS (合规)
m > 对应频段限值        → FAIL (超标)
m < 1% (噪声门限)      → PASS (<1%)，避免噪声主频误判
```

## 4. IEEE 1789-2015 参考（国标的蓝本）

IEEE 1789 在 (频率 f [Hz], 调制深度 m [%]) 平面上给出两档推荐实践（非强制）：

**NOEL（无可观察效应）**：f≤90Hz → m≤0.01×f；90~300Hz → m≤0.0333×f；>300Hz 豁免
**Low Risk（低风险）**：f≤90Hz → m≤0.025×f；90~1250Hz → m≤0.08×f；>1250Hz 豁免
**f ≤ 8 Hz**：建议完全避免。

90 Hz 是分界点：低于 90 Hz 闪烁可被人眼直接感知，限值最严格；高于 90 Hz 风险转为
频闪效应为主。这也是高频 PWM 调光（>1.25 kHz）被广泛推荐的原因。

### 国标 vs IEEE 1789 数值对比

| 频率 | GB 40070 限值 | IEEE NOEL | IEEE Low Risk |
|---|---|---|---|
| 10 Hz | 0.1% | 0.1% | 0.25% |
| 60 Hz | 0.6% | 0.6% | 1.5% |
| 100 Hz | 3.2% | 1.0% | 8.0% |
| 120 Hz | 3.84% | 1.2% | 9.6% |
| 500 Hz | 16% | 豁免(>300) | 40% |
| 2 kHz | 64% | 豁免 | 豁免(>1250) |

结论：GB 40070 总体介于 IEEE 的 NOEL 与 Low Risk 两线之间——低频段与 NOEL 一致，
90Hz 以上比 NOEL 宽松但比 Low Risk 严格，高频豁免线放宽到 3125Hz。

## 5. 本项目中的实现（V2.x 固件）

- **f 取自 FFT 主频**：4096 点 FFT @ 20 ksps，对 5 块频谱做幅度平均后用 `majorPeak()`
  （对数域抛物线插值）提取主导闪烁频率，分辨率 4.88 Hz。
- **m 取自波动深度**（= Percent Flicker）：报告窗口（约 1.024 s，20480 样本）内峰谷值计算。
- 判定函数 `gb40070Zone(f, m)`（src/flicker.cpp）：

```c
static uint8_t gb40070Zone(float f, float m)
{
    if (f > 3125.0f) return 2;              // 高频豁免

    float limit = (f <= 10.0f)  ? 0.1f
                : (f <= 90.0f)  ? 0.01f  * f
                :                 0.032f * f;
    return (m <= limit) ? 0 : 1;            // 0=合规 1=超标
}
```

- **WiFi 网页仪表**（src/webdash.*）：S3 开 AP 热点 `LightSense`（密码 `lightsense`），浏览器访问
  `http://192.168.4.1`，WebSocket 每报告窗口推送 JSON 快照（波形包络 / 频谱 / 指标）实时刷新。
  网页含三个页面（顶部按钮切换）：**频闪仪**（实时指标 + 波形 + 频谱）、**LED 控制**、**教室测量**。
- **LED 频率输出**（src/led_pwm.*）：D8 = GPIO21 → 220~330Ω → LED → GND，LEDC 硬件 PWM 占空比 50%，
  模式：常亮 / 50 Hz / 100 Hz / 500 Hz / 1 kHz / 5 kHz（常亮为 GPIO 恒亮 100%）。
  网页「LED 控制」页切换（`GET /led`，`?mode=const|50hz|100hz|500hz|1khz|5khz`），
  与测量互不干扰——把光传感器对准外接 LED 即可闭环自测（主频应跟随输出频率）。
- **教室灯光测量**（src/classroom.*）：面向教室照明验收场景，支持多灯具依次测量并可打标签
  （留空自动编号）。单次测量固定 29 个报告窗口 ≈ 30 s，聚合：波动深度均值/峰值、Flicker Index、
  Pst^LM 均值/峰值、主频（取频谱能量最大窗口）。
  判定口径：**波动深度 30s 均值** vs 国标表 4 限值（按主频分段）+ **Pst^LM 30s 均值 ≤ 1**；
  m < 1% 视为噪声直接 PASS，f > 3125 Hz 高频豁免。
  记录 NVS 断电保存（最多 50 条），网页可导出 CSV（带 BOM，Excel 直接打开）。
  API：`GET /api/classroom`（状态+记录）、`POST /api/classroom/start?label=`、`POST /api/classroom/clear`。
- **串口输出示例**：

```
Flicker  : 5.02 %
Freq     : 100.10 Hz
Zone     : GB40070 FAIL
```

## 6. 已知局限

1. **主频简化**：国标按光输出波形各频率分量评估；本实现仅用主频 + 整体波动深度，
   多频率成分叠加的波形未逐谐波判定（可由 FFT 幅度谱扩展实现）。
2. **频率分辨率**：4.88 Hz bin 宽度使 <15 Hz 频段的主频提取精度有限。
3. **噪声门限**：m < 1% 直接判 PASS，掩盖了 f≤10Hz 频段 0.1% 的严格限值场景
   （实测噪声本底约 0.1~0.5%，无法可靠分辨）。
4. **Pst^LM 为短时估计**：实时仪表为 1.024 s 瞬时值；教室测量模式聚合 30 s 均值，
   仍非标准要求的 10 分钟统计评估器。
5. **教室测量的代表性**：单测点只反映测点位置光照，教室验收应多点测量（中心 + 四角等）并用标签区分；逐窗均值会平滑掉 30 s 内的短时波动（峰值栏可参考）。

| 场景 | f | m | GB 40070 判定 |
|---|---|---|---|
| 恒定直流光照 | — | <1% | PASS (<1%) |
| 线性电源 + 50Hz 市电灯 | 100 Hz | 5% | FAIL（限 3.2%） |
| 优质恒流驱动 | 100 Hz | 1% | PASS（限 3.2%） |
| 普通整流 LED 驱动 | 100 Hz | 10% | FAIL |
