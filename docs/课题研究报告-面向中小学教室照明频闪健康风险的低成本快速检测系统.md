# 课题研究报告

# 面向中小学教室照明频闪健康风险的低成本快速检测系统

> 课题成果载体：LightSense —— 基于 ESP32-S3 的便携式教室照明频闪健康风险检测仪表
> 报告日期：2026 年 10 月

---

## 摘要

随着我国持续推进儿童青少年近视防控与教室照明改造，LED 灯具在中小学教室中大规模普及，但"照度达标"并不等于"频闪达标"，部分灯具仍存在肉眼不易察觉的频闪问题，长期暴露可能影响视觉舒适度与学习体验。现有专业频闪检测设备价格昂贵、操作复杂，难以在学校场景普及。本课题基于 ESP32-S3 平台，采用"高速 ADC 采样 + FFT 频谱分析"的技术路线，研制了一套低成本便携式教室照明频闪健康风险检测系统。系统实时计算波动深度（Percent Flicker）、Flicker Index、Pst^LM（IEC TR 61547-1）与 SVM（IEC TR 63158）等国际通用评价指标，按"光照量程前置否决 + Pst^LM ≤ 1 + SVM ≤ 0.4"口径自动完成健康风险判定，并提供网页实时仪表、OLED 本地显示、五键离线操作、标准 LED 闪烁源自校验、标准五点教室巡检闭环（教室级 A/B/C 健康结论、整改建议、整改前后复测对比与一页式摘要报告导出）、多灯具测量与历史记录、云端数据通道及灯具趋势分析（恶化预警）功能。经标准闪烁源闭环自校验与多版本迭代验证，系统以极低的硬件成本实现了接近专业频闪仪的核心检测能力，形成"看得见、测得到、用得起"的校园照明健康检测工具。

**关键字**：教室照明；频闪（Flicker）；时间光伪像（TLA）；Pst^LM；SVM；ESP32-S3；FFT 频谱分析；近视防控；教室巡检；低成本检测；趋势分析

## 一、课题研究起源

### 1.1 政策与时代背景

儿童青少年近视防控已上升为国家战略。教育部等部门陆续出台教室照明改造相关技术指引，各地学校大规模更换 LED 教室灯与黑板灯。然而照明改造验收多聚焦于**照度、照度均匀度**等静态亮度指标，对灯具**时间维度的光输出波动（频闪）**关注不足。

### 1.2 问题提出

频闪（Flicker）是光源亮度随时间的周期性波动。研究表明，低频或深度调制的光输出可引起视觉疲劳、头痛，并与近视发生发展存在关联风险；即使波动快到肉眼无法察觉（如 100 Hz 以上），仍可能通过时间光伪像（Temporal Light Artifact, TLA）机制影响视觉系统。部分"达标"教室灯具实际存在不可察觉的频闪，构成了健康用光的隐性风险。

### 1.3 现有检测手段的不足

- **专业频闪仪**价格昂贵（数千至数万元）、操作专业，学校难以配备；
- **照度计**只能测亮度，无法反映光输出的时间波动；
- **手机 APP 类工具**受采样率与传感器限制，测量口径不标准、结果不可比。

学校场景缺乏一种**用得起、看得懂、测得准**的频闪检测手段，导致"改造后是否真正健康"无法自行验证。

### 1.4 研究目标

研制一套面向中小学教室照明、面向非专业人员操作的低成本快速频闪健康风险检测系统，具体目标：

1. 实现波动深度、Flicker Index、Pst^LM、SVM 等国际通用指标的真实测量；
2. 依据现行标准口径自动判定"合规 / 超标 / 光照异常"，非专业人员可直接读取结论；
3. 集成标准闪烁源实现闭环自校验，保证测量可信；
4. 支持标准五点教室巡检与多灯具打标签测量、数据留存与一页式报告导出，服务照明改造验收与长期跟踪；
5. 整机成本控制在专业设备的零头水平。

## 二、课题研究综述

### 2.1 频闪的产生机理

LED 灯具由驱动电源供电，当驱动采用单级功率因数校正（PFC）或调光控制时，输出电流含低频纹波（100 Hz 及其倍频），光输出随之周期性波动；劣质驱动、老化器件或调光设置不当会加剧波动。波动深度越大、频率越低、占空比越不对称，频闪风险越高。

### 2.2 评价指标与标准演进

| 标准 | 关键内容 | 本课题的采用 |
|---|---|---|
| IEEE Std 1789-2015 | 定义波动深度（Percent Flicker）、Flicker Index；给出 NOEL / Low Risk 推荐线 | 采用其指标定义（仅展示，不判定） |
| GB 40070-2021《儿童青少年学习用品近视防控卫生要求》 | 曾以波动深度限值表为主（≤10 Hz → 0.1%；10~90 Hz → 0.01×f；90~3125 Hz → 0.032×f；>3125 Hz 豁免），与 IEEE NOEL 线同源 | 作为背景与历史口径参考 |
| IEC TR 61547-1 | Pst^LM 短时闪烁严重度（照明设备闪烁计权），标准统计窗口 10 分钟；Pst = 1 为 50% 人群察觉阈 | 判定指标之一（≤ 1） |
| IEC TR 63158 | SVM 频闪可见度，SVM = 1 为 50% 人群可见阈 | 判定指标之一（≤ 0.4） |
| EU (EU) 2019/2020 生态设计法规 | 自 2024-09 起要求 LED 光源 Pst^LM ≤ 1 且 SVM ≤ 0.4 | 综合判定口径的国际接轨依据 |
| 教育部教室照明改造技术指引 | 采用"Pst^LM ≤ 1"口径 | 与国标指引接轨 |

**综述小结**：评价指标已从单一的时域波动深度，演进为"时域指标 + 频域计权指标"并重；Pst^LM（覆盖 < 80 Hz 低频段）与 SVM（覆盖 80~2000 Hz 频段）分频段互补，构成当前国际上认可度最高的频闪合规判定组合。

### 2.3 检测技术现状

专业频闪仪（如实验室级光度探测 + 高速采集系统）精度高但成本高、不便于多点巡检；手机方案受 30~60 fps 摄像头采样率限制，只能粗判 100 Hz 以下成分；照度计 + 示波器的组合操作繁琐且需要专业知识。**面向学校一线的"低成本 + 标准口径 + 自动判定"三合一方案目前仍是空白**，这正是本课题的切入点。

## 三、课题研究过程

### 3.1 总体技术方案

系统采用"传感 → 高速采样 → 频谱分析 → 指标计算 → 自动判定 → 多端呈现"的链路，硬件主控选用 ESP32-S3（8 MB Flash），兼顾 ADC 性能、WiFi 联网与成本。

```
光传感器 ──► ADC+DMA 连续采样 ──► 窗口统计/FFT ──► Pst^LM / SVM / m / FI ──► 综合判定
                                                                        ├─► OLED 本地显示
                                                                        ├─► 网页实时仪表 (WiFi AP + WebSocket)
                                                                        ├─► 教室测量记录 (NVS / CSV / 云端)
                                                                        ├─► 教室巡检五点闭环 (A/B/C 汇总 + 复测对比 + 一页式报告)
                                                                        └─► 灯具趋势分析与预警
```

### 3.2 硬件设计

| 模块 | 方案 | 关键设计 |
|---|---|---|
| 光信号输入 | 光电传感器 → GPIO1（ADC1_CH0） | 12 bit、12 dB 衰减（满量程约 3.1 V）；建议靠近引脚加 RC 低通（1 kΩ + 10 nF，截止约 16 kHz），既满足采样保持回充要求，又对 5 kHz 内显示频带几乎无衰减 |
| 高速采样 | SAR ADC + DMA 连续模式 | 20 ksps 硬件时钟定节拍，双缓冲分块搬运，规避 CPU 定时抖动 |
| 标准闪烁源 | GPIO17 经限流电阻驱动外接 LED | LEDC 硬件 PWM 输出常灭/常亮/50/100/500/1000/5000 Hz 方波（占空比 50%），用于闭环自校验 |
| 本地交互 | 1.54" SSD1309 OLED（SDA=GPIO4, SCL=GPIO5）+ 五键薄膜按键（GPIO38~42，公共端接 GPIO21 虚拟地） | U8g2 **软件模拟 I2C** 驱动，规避 arduino-esp32 2.0.x 硬件 I2C 在总线异常时的阻塞初始化问题；中文全量字库，8 MB 分区表支撑 |
| 联网 | WiFi AP（`LightSense`）+ 可选 STA | AP+STA 共存：现场演示走设备热点（http://192.168.4.1，断网可用），配网后可接 OneNET 云端 |

### 3.3 信号处理与指标算法（度量层）

1. **时域统计**：每个窗口内取峰谷值计算波动深度 `m = 100%×(A−B)/(A+B)`（与国标"波动深度"公式相同）；计算均值线以上面积比得 Flicker Index；
2. **频谱分析**：每块 4096 点去直流 + Hann 窗 FFT（分辨率 4.88 Hz），5 块幅度累加归一化为单块平均，显示 4.9 Hz ~ 5 kHz 对数轴频谱；
3. **主瓣簇提取（Hann 窗泄漏校正）**：对局部极大值取 3 bin 幅度和÷2 恢复真实幅度，抛物线插值确定真实频率后**单次**加权，避免非 bin 中心频率的分量被相邻 bin 重复计入平方和；
4. **Pst^LM（IEC TR 61547-1）**：`m_k = 2|X_k|/|X_DC|`（DC 基准 = 窗口实测均值 × N/2，Hann 窗等效直流幅度），人眼加权 H = 1/可见阈值（以 8.8 Hz 处 0.25% 正弦单独贡献 Pst = 1 为标定点），>35 Hz 阈值按闪烁仪二阶低通滚降外推（thr ∝ f²）至 80 Hz，`Pst = √(Σ(m_k·H(f_k))²)`；
5. **SVM（IEC TR 63158）**：取 80~2000 Hz 频段，可见阈 `T(f) = 2.865×10⁻⁵·f^1.543 + 0.225`，按 3.7 次方 Minkowski 范数求和 `SVM = (Σ(C_m/T(f_m))^3.7)^(1/3.7)`。

### 3.4 综合判定模型（v1.1 口径）

```
① 光照量程前置检查（窗口均值 ADC 码，阈值可调）
   < 400 → 光线过暗（DC 基准过小，Pst/SVM 噪声底虚高）→ 一票否决
   > 3000 → 光线太亮（接近满量程，可能削顶引入假谐波）→ 一票否决
② 光照正常时双指标判定
   Pst^LM ≤ 1（IEC TR 61547-1）
   SVM    ≤ 0.4（IEC TR 63158 / EU 2019/2020）
```

判定码共 8 档（0 合规 PASS / 2 超 Pst^LM / 3 双超 / 5 超 SVM / 6 光线过暗 / 7 光线太亮，另有 1、4 为旧记录遗留口径），频闪仪页与教室测量共用同一口径，并在串口、网页 JSON、OLED 界面间保持一致映射。

### 3.6 验证与测试

**标准闪烁源闭环自校验**：用系统自带 LED 输出已知频率与波形的方波，把光传感器对准 LED，验证主频跟随输出频率、指标量值符合理论预期：

| LED 模式 | 主频 | 波动深度 | Pst^LM | SVM | 预期判定 |
|---|---|---|---|---|---|
| 50 Hz | ≈50 Hz | ≈100% | ≈24 | ≈1.5 | 超标 · 双项 |
| 100 Hz | ≈100 Hz | ≈100% | ≈0 | ≈4.9 | 超标 · SVM |
| 500 Hz | ≈500 Hz | ≈100% | 0 | ≈2.0 | 超标 · SVM |
| 1 kHz | ≈1 kHz | ≈100% | 0 | ≈0.88 | 超标 · SVM |
| 5 kHz | ≈5 kHz | ≈100% | 0 | ≈0 | 合规 PASS |
| 常亮 | — | <1% | 0.02~0.1 | ≈0 | 合规 PASS |

其中 100 Hz / 100% / 50% 方波的 SVM 理论值为 4.9，系统复算结果 4.90，验证了 SVM 算法实现的正确性。传感器遮光时判定显示"光线过暗"、强光直射近满量程时显示"光线太亮"，验证了量程前置否决逻辑。

## 四、课题研究结论

### 4.1 主要成果

1. **研制完成整机系统**：形成从传感器到云端的全链路可用设备，硬件以 ESP32-S3 开发板 + 少量外围器件实现，成本仅为专业频闪仪的零头；
2. **实现四指标真实测量**：波动深度、Flicker Index、Pst^LM、SVM 均按国际标准算法实现（含 Hann 窗泄漏校正、DC 基准标定、3.7 次方 Minkowski 范数等关键细节），非简化估算；
3. **自动健康判定**：按"光照量程前置否决 + Pst^LM ≤ 1 + SVM ≤ 0.4"口径输出 8 档判定结论，非专业人员无需理解指标即可读取"合规 / 超标 / 光照异常"；
4. **标准闪烁源自校验**：内置 7 档 LED 输出（常灭~5 kHz），随时闭环验证主频与指标量值，提高测量可信度；
5. **完整的数据链**：教室多灯具打标签测量（30 s / 1 min / 10 min 三档），NVS 断电保存 80 条（约 16 次五点巡检）并带真实测量日期，CSV 导出（Excel 直开），可选 OneNET 云端补传；
6. **趋势分析与早期预警（特色成果）**：对同一灯具定期复测，系统自动进行 Theil-Sen 稳健回归趋势分析，给出"稳定 / 缓慢恶化 / 明显恶化 / 改善"等级与"预计 N 周后越过限值"的预测，并独立检查光照均值下降以提示**光衰或积灰**（该信号往往早于频闪指标恶化出现），把检测从"单次合规判定"升级为"灯具全生命周期健康跟踪"；
7. **教室巡检闭环与报告输出（特色成果）**：按标准五点测点（中心 + 四角）逐点测量，**设备端**自动汇总教室级结论——A 合规（5 点全部合规）/ B 局部异常（1~2 点异常且中心正常）/ C 整体异常（≥3 点异常或中心异常）——并按风险成因给出针对性整改建议（低频 Pst^LM 超标 / SVM 超标 / 光照偏暗偏亮 / 共性供电问题 / 单灯具故障等）；支持整改前后两次巡检**逐点复测对比**（整改有效 / 指标恶化 / 光照下降识别）；一键生成**一页式「教室巡检摘要」报告**（基本信息、点位结果表、教室级结论、整改建议、复测对比，浏览器直接打印或存 PDF 归档），把检测升级为"测量 → 判断 → 建议 → 整改 → 复测 → 报告"的完整治理闭环；
8. **三级人机界面**：网页实时仪表（波形/频谱/指标，支持大屏演示模式）、OLED 本地中文显示（含巡检进度与上次巡检结论）、五键离线操作，适配演示、巡检、验收多种场景。

### 4.2 创新点

1. **低成本专业级检测**：以消费级 MCU 实现接近专业频闪仪的核心检测能力，大幅降低校园检测门槛；
2. **指标直观化**：将复杂的国际标准指标转换为直观的健康风险等级，非专业人员快速使用；
3. **标准闪烁源自校验**：集成标准 LED 频闪源闭环自测，测量可靠性可自查；
4. **从单点检测到教室级巡检闭环**：标准五点测点 + 设备端教室级 A/B/C 汇总 + 成因化整改建议 + 复测对比 + 一页式报告导出（配合日期戳趋势分析与云端补传），为学校照明改造验收和长期健康用光管理提供"测量 → 判断 → 建议 → 整改 → 复测"的完整数据依据。

### 4.3 应用示范

现场演示的标准流程（不依赖外部网络）：设备开热点 → 手机连接 → 访问 `http://192.168.4.1` → 切换"演示模式"并全屏投屏。教室验收使用**标准五点巡检**：网页新建巡检（填教室号 / 场景 / 巡检人）→ 按中心 + 四角逐点测量 → 设备端自动给出教室级 A/B/C 结论与整改建议 → 一键导出一页式摘要报告打印存档；整改完成后对同一教室再次巡检，报告自动附上前后复测对比。对同一灯具定期（如每周）用相同标签复测，即可在"灯具趋势分析"卡片中查看指标随时间的变化并获得恶化预警。

### 4.4 局限与展望

**局限**：
1. 频闪仪页 Pst^LM 为 1 s 窗值（读数存在正常窗间抖动），标准统计口径为 10 分钟，以教室测量 10 min 档最接近；
2. 4.88 Hz bin 宽度使 < 15 Hz 频段主频提取精度有限；主频仅取频谱能量最大分量作代表；
3. 教室级 A/B/C 结论为标准五点测点的分档汇总（快速普查口径），未做标准测量方法要求的网格布点与照度均匀度计算，正式验收仍应依据 GB/T 5700 等标准测量方法；
4. SVM/Pst 实现遵循标准算法但未经计量认证，适用于工程评估与横向对比，不替代实验室级频闪仪；
5. NVS 保存 80 条记录（约 16 次五点巡检），长期归档需导出 CSV / 报告 PDF。

**展望**：
1. 计量比对：与实验室级频闪仪开展对比测量，探索校准系数；
2. 扩展 TLA 指标：跟进 IEC 系列标准的频闪以外时间光伪像评价（如频闪幻像 Stroboscopic effect 的 SVM 已覆盖，可补充 MP 口径）；
3. 数据规模化：云端历史数据长期归档与校级照明健康档案；
4. 推广应用：向更多学校推广，形成区域性教室照明频闪数据库，支撑照明改造决策。
