# LightSense 开机 Logo 设计稿（128×64，3 版候选）

> 仅设计稿与草图；**未修改任何固件代码**，`src/` 保持原样。

## 结论

**推荐 A 版「环形光感 · 英文横排」**：信息层级最完整（图形 + 品牌 + 品类 + 版本），新增 Flash 仅 5,842 B（≈5.7 KiB），无堆分配，纯 ASCII 使开机首帧不依赖 GB2312 字库。B 版为 **0 字节新增字库**的兜底方案（适合 Flash 余量紧张或必须中文的场景），C 版为图形主导的变体（适合放大图/宣传物料，但屏上信息最少）。

## 共同母题（三版同源）

- **圆环** = 镜头 / 灯具口径；**环内折线** = 频闪波形（光输出随时间的波动）；**左右两道短光条 + 顶部光点** = 发光方向。
- 三版只改变「图形占比 / 字重 / 信息密度」，不改母题，避免风格分裂。
- 图形全部用 U8g2 基础图元绘制（`drawCircle` / `drawLine`），不引入位图/XBM，不占用额外常量数组。

## 首帧时序

1. 上电 → `setup()` → `oledBegin()`：`u8g2.begin()` 完成 SSD1309 初始化（软件 I2C，约 10–30 ms 量级，无 ACK 探测）。
2. 设计上在 `oledBegin()` 末尾绘制 logo 并 `sendBuffer()`：整帧传输 40–80 ms → **开机后约 50–110 ms 见到 logo**。
3. **何时被覆盖**：首个报告窗口（≈1.024 s）的例行 `oledShow()` 首次重绘为正式页面，logo 可见时长 ≈ **0.9–1.0 s**。
4. 若在此之前有按键：`oledHandleKey()` 立即重绘（[oled.cpp L424](file:///c:/Users/cnh79471/OneDrive%20-%20Signify/Documents/Github%20projects/LightSense/src/oled.cpp#L424)）会提前替换 logo。
5. **「至少显示 N 毫秒」兜底（仅设计说明）**：在 `oledBegin()` 记录开机时刻；按键处理入口若 `millis() - bootMs < 800`，只更新交互状态、暂不重绘（首个报告窗口 1.024 s 到来时自然接上）。不采用 `delay()` 阻塞——主循环需保持 ADC 采集与报告节拍。取 800 ms 是为首个报告窗口留 200 ms 余量。

## 落地成本

- **Flash（字体数组实测字节数，取自 `u8g2_fonts.c` 声明）**：`wqy12_t_gb2312` = 202,690 B，`wqy16_t_gb2312` = 308,472 B，`helvB14_tf` = 3,681 B，`6x13_tf` = 2,161 B，`logisoso16_tf` = 3,048 B。
- **堆**：三版均不 `new`/`malloc`、无新增常驻缓冲；字库为 `const`（驻留 Flash），绘制复用现有 1 KB u8g2 全缓冲。对项目敏感的堆占用为 **0**。
- **代码量**：每版新增绘制函数约 20–40 行，无额外数据结构。
- **中文字库代价**：GB2312 全套两档合计 511 KB（198 + 301 KiB）。B 版字体已在固件中链接，增量为 0；若要单独引入中文只需其中一档也要 +198/301 KiB。因此 **A/C 的纯英数路线在 Flash 上是显著优势**。

## 纯英数在专利/产品语境下的可接受性

- 产品名 `LightSense` 本身是英文标识，屏上保留英文与商标呈现一致，不产生额外中文译名歧义。
- 专利附图通常以英文/图形标号呈现界面元素，中文说明写在交底书正文；附图中的品牌字标按原样保留英文是常规做法。
- 开机路径不依赖 GB2312 字库，减少首帧字形/字库加载的不确定性，也避免因裁剪中文字库而使现有 3 个页面的中文失效。

## 风险与备注

- A：+5.7 KiB Flash（相对 CJK 字库很小），但若分区余量<8 KB 需改用 B；6×13 副标在 1.54″（约 0.24 mm 像素间距）上偏细，若嫌弱可换 `u8g2_font_6x13B_tf`（粗体，体积另计）。
- B：中英同行时基线共用，拉丁字母视觉上略低于中文重心（字号 16/12 混排的正常现象）；副标 107 px，左右余量 10/13 px，面板列偏移时仍安全。
- C：无品类与版本文字；环顶 y=1 距上边缘仅 1 px，若面板存在列/行偏移，建议整体下移 1–2 px。
- 三版均为**静态单帧**，不做开机动画；logo 生命周期仅到首个报告窗口为止。

## 复现方式

128×64 逐像素绘制后 4× 最近邻放大（512×256，白底黑像素，黑=点亮）。字形由固件同款 U8g2 点阵字库（`u8g2_fonts.c` 内数组）解码出真实位图，**未使用系统字体近似**；圆环按 `u8g2_draw_circle` 的同一中点算法生成。原始 17 张页面草图未改动，本文件只新增 3 张 logo 草图。
